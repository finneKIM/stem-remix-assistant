# 모델 비교 — EXP-002 vs EXP-003

두 파이프라인(EXP-002 MusiConGen, EXP-003 MusicGen-Melody/Style)을 동일 스템·동일 프롬프트 조건으로 각각 실행한 뒤 비교한다.

## 비교 항목

| 항목 | 설명 |
|---|---|
| BPM 오차 | madmom으로 측정한 원곡 BPM과 재생성 스템 BPM의 차이 |
| Beat alignment | 원곡과 재생성 스템의 비트 그리드 일치도 |
| Onset alignment | 원곡과 재생성 스템의 온셋(타격 시점) 일치도 |
| 청취 평가 | 직접 들었을 때 원곡과 자연스럽게 어울리는지 주관 평가 |
