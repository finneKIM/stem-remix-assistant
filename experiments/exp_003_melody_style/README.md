# EXP-003 — MusicGen-Melody/Style 파이프라인 (예정)

## 목적

원곡 오디오를 직접 참조하는 MusicGen-Melody/Style로 재생성했을 때, 원곡과의 음악적 유사성(멜로디·음색)과 정렬 품질이 EXP-002 대비 어떤지 검증.

## 방법

`config.yaml` 참고. 파이프라인 전체 구조는 Notion "02번 노트북 — 재생성/재조합 로직 설계" 페이지의 다이어그램 참고.

## 예상 트레이드오프

원곡 유사성은 높을 것으로 예상되나, BPM은 텍스트 프롬프트 삽입 수준의 약한 신호라 EXP-002보다 정렬 보정이 더 필요할 수 있음.
